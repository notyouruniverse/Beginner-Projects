           - A python program designed to calculate if a given number is prime or composite.

        11. Palindrome Checking
           - A python program that verifies if an input string is palindrome using lists.

           - A program that works on file system in python to create and view saved passwords.

        13. Student detail record
           - A simple student detail storehouse that works on the basis of dictionaries.

        14. To do list
